Use the topic notes for orientation and the bundled manuals as the authority.

## Process

1. Pick the matching row below and read that topic note.
2. Open [`CORPUS.md`](references/CORPUS.md), find the matching topic, and open its named `.txt` extract.
3. Search the extract by heading or distinctive UI term. Read enough surrounding text to preserve prerequisites, limits, and product distinctions.
4. Base the answer or procedure on both sources. Cite the manual key and printed page or chapter when useful.

Do not answer a product-specific task from the topic note alone. Done means the matching topic note and at least one authoritative extract have both been applied.
