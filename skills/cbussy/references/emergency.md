# Emergency lighting

5500NAC2 module. AC2 does not host it.

Fittings → groups → optional automatic test scheduler. Objects can come from Commission (DALI-2 emergency) or the controller.

Function test is short. Duration test is the battery discharge. Stop-in-progress is in the E&E module. Reports: group and individual. Email goes to users, not admin. Those users need scheduler access and membership of the test group.

URL pattern: `/scada-vis/emergencyexitlight`.

UG ch.6 and WB p.306–318 via [`CORPUS.md`](CORPUS.md).
