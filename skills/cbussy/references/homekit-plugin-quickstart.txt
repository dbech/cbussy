Aim of this Document
The aim of this document is to highlight recommended steps & tips on:

• Downloading & Installing the controller plugin for Apple HomeKit

  Schneider Electric Cloud Service

HomeKit Structure

         Bridge

  In HomeKit, a bridge allows a non -HomeKit device to be connected to the
  HomeKit app; in this example, the C -Bus Controller is added as a Bridge




         Lights

  Lights are a dedicated category in HomeKit, this is important to
  remember as it will influence how devices will be named when they are
  added into the app




 Naming Convention
 Any device that is added in HomeKit is assigned a name, representing how it
 is displayed in the user interface.

 The following is a recommended naming format that can be used when
 adding devices:

        [Room / Location] + [Descriptor / Function]

 Examples when adding lights :
  • Kitchen bench → lights over kitchen bench
  • Lounge Couches or Couches → lights over the couches in the lounge

 This naming convention is used to help optimise how devices are displayed
 in the HomeKit app and how the end user interacts when controlling the
 devices via Siri .

It was highlighted earlier that to establish an initial connection between
the C -Bus Controller & HomeKit, both the controller & smart phone need
to be on the same internet supported Wi -Fi Network




   Once C -Bus objects have been added as devices in the HomeKit app, an
   internet connection is not required for them to be controlled using the app.

   This is because commands between the smart phone & controller are
   achieved through the Wi-Fi protocol & not the internet connection.

   As long as the smart phone & C -Bus Controller are on the same Wi         -Fi
   Network , manual control using HomeKit is still possible.

HomeKit & Scenes

 There is a key difference between the capabilities of the HomeKit app & the
 visualisations achieved in a C -Bus Controller.




                                 C -Bus Controller – Custom Visualisation
                                 The custom visualisation in the C -Bus
                                 Controllers can present multiple scenes via
                                 a single button if all scenes share the same
                                 Trigger Group:

                                 1 Dedicated Button → Multiple Scenes

                                 This feature allows for multiple icons, each
                                 housing multiple scenes to be placed on the
                                 same Page .




                                 Apple HomeKit app
                                 Each scene is represented using a dedicated
                                 button:

                                 1 Dedicated Icon Button    → 1 Scene

                                 HomeKit does not support the ability for
                                 multiple scenes to be selected from a
                                 dedicated button.

                                 A workaround is creating a separate Room
                                 in the app and adding appropriate scenes to
                                 that Room
